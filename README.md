# 🌐 Care Guard Solution Website

A professional business website for **Care Guard Solution**, providing security guards, home nursing, and manpower services across Karnataka.

---

## 🚀 Live Website

👉 https://sharanaks.github.io/newone/


---

## 📌 Project Overview

This project is a fully responsive business website designed for a service-based company.
It helps customers easily understand services and contact the business.

---

## ✨ Features

* 📱 Fully responsive (Mobile + Desktop)
* 🎞️ Image slider with animation
* 📞 Call, WhatsApp, and Direction buttons
* 📄 Multi-page navigation (Home, About, Services, Contact)
* 📝 Contact form integration
* ⚡ Fast loading (static website)
* 🔍 Basic SEO optimization

---

## 🛠️ Technologies Used

This website is deployed using **GitHub Pages**.

Steps:

1. Push code to GitHub
2. Go to repository settings
3. Enable GitHub Pages (main branch)
